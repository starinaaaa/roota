## Публикация

Цель — НОВЫЙ стенд `roota-preview` у приложения Timeweb `roota` (269503).
`roota.moscow`, его ветка `main` и стенд `roota-migration` (6129) не меняются.
Создание стенда ещё НЕ завершено: открыта форма нового стенда; дальнейший доступ
к Safari остановлен блокировкой Mac. Ссылка и опубликованный коммит появятся после
создания стенда и фактической проверки его URL.

Для backend-приложений стенды бесплатны и используют ресурсы существующей машины:
https://timeweb.cloud/docs/apps/stands. Новые платные сервисы не заказаны.

Команды ветки `npm run build` и `npm start` намеренно запускают только `preview/`.
Нельзя сливать эту ветку в `main`: в ней также переключены команды запуска.
В Timeweb следует выбрать эту ветку и её готовый коммит, оставить список переменных
пустым; не выбирать переменные основного приложения. Домены и конфигурацию
основного деплоя не менять. Форма нового стенда: вкладка «Стенды» → «Добавить стенд».

## Изоляция

Это безопасная демонстрационная реализация интерфейса, разрешённая заданием,
а не копия рабочей базы магазина.

- Сборка отдельного Next.js-приложения `preview/`; рабочие страницы, API, Server
  Actions, авторизация, фоновые задания и модули интеграций в него не входят.
- Запускающий скрипт передаёт дочернему процессу только системные переменные,
  PORT и NODE_ENV. DATABASE_URL, ключи S3/Robokassa/Ozon/UniSender/Telegram,
  JOBS_ENABLED и NEXT_PUBLIC_* не передаются даже при случайном наследовании.
- Корзина и введённые пользователем тестовые контакты — sessionStorage вкладки,
  без сетевой отправки. Чужие корзины и данные покупателей не копировались.
- Сервер принимает только GET/HEAD. POST возвращает 405, рабочие API и админка —
  404. Нет записи заказов, остатков, резервов, подписок, писем или отправлений.
- Оплата — явно обозначенный локальный симулятор, без банковских реквизитов.
  Состояние «Недоступна проверка оплаты» означает неизвестный статус.
- Доставка — демонстрационные 350/550 ₽ и 3–5 дней, явно подписанные как учебные
  значения; это не коммерческие условия и не ответ API перевозчика.
- Рабочая аналитика не загружается. Её определения и отчёты исходного магазина
  не менялись; события стенда туда не отправляются.
- `robots.txt` запрещает весь сайт, метаданные и HTTP X-Robots-Tag содержат noindex.
- CSP запрещает внешние соединения/изображения/фреймы. В production нет unsafe-eval;
  локальный dev разрешает его только для стандартного webpack React Refresh.

У Timeweb стенд делит вычислительные ресурсы с основным приложением. Это не
изолированная виртуальная машина; зато код и данные приложения разделены явно.

остаётся лишь для совместимости внутри исходной функции; в интерфейсе его нет.

каждого вида, автор подбирает формы и цвета. Согласование фото и палитры не обещается.

## Недостающие материалы и решения

- Одиночные ракурсы каждой тарелки: просмотрены все 20 существующих фото; везде
  присутствуют стопки или другие изделия. Поэтому первые фото сохранены, а цена
  подписана за одно изделие.
- Фото точно проверенного состава каждого готового набора сада. До их появления
  все композиции честно подписаны примерами.
- Масштаб деталей сада в руке или рядом с понятным предметом.
- Короткое видео сборки и падения/перестройки композиции. Галерея поддерживает
  необязательный видеофайл с постером; пустого блока без файла нет.
- Редакционное подтверждение новых текстов от первого лица.
- Возможность выбора конкретных форм/палитры и согласования фото требует
  отдельного решения владельца; сейчас не предлагается.
- При необходимости теста реальной интеграции потребуется изолированная тестовая
  база и тестовые настройки провайдеров. Их стоимость/создание не согласовывались,
  новые ресурсы не заказывались.
