# Чек на странице покупателя и служебное письмо

Страница `/market/pay/[token]` сохраняет состояние покупки после обновления. Подтверждённый чек текущей покупки доступен через «Открыть чек» и «Скачать чек PDF». До подтверждения показано ожидание; при ошибке — обращение к продавцу. Исходное состояние оплаты не меняется.

Для наличных/перевода сохранение почты и выдача чека могут происходить в любом порядке. Последнее из этих событий ставит одно служебное письмо `market_receipt` в действующую очередь. Письмо не зависит от согласия на новости/отзыв. Тестовые продажи писем не создают. Повторы не создают второе письмо. Страница показывает фактический статус очереди/доставки; принятие провайдером не называется доставкой.

Новый публичный GET `/api/market/pay/[token]/receipt` отдаёт PDF только по случайному токену конкретной оплаченной покупки с проверенным оригинальным чеком. Нет доступа к другим покупкам, кабинету продавца или ключам помощника. Документ получает общие ограничения домена ФНС, запрет редиректов, таймаут и предел 8 МБ. Робокасса сохраняет свою фискализацию и почтовую выдачу, без нового чека НПД.

Проверено: 20 тестов расчётов/состояний/почты/проверки документа; 14 мобильных сценариев на эмуляции iPhone 13 и iPad Mini; реальный локальный API скачивания с изолированными тестовыми продажами, включая отказ для неизвестного токена, неподтверждённого чека и Робокассы; Next production build, TypeScript, ESLint. Отчёт и синтетические скриншоты — `artifacts/market/buyer-receipt/`.

Повтор проверки UI: `PLAYWRIGHT_MODULE=<путь к установленному playwright> ROOTA_TEST_URL=http://127.0.0.1:3163 node scripts/check-market-buyer-receipt.mjs`. Проверка download API требует отдельной локальной БД `roota_npd_helper_preview`, локального сервера с тестовой подменой публичного документа ФНС и `DATABASE_URL`; реальную ФНС для этих тестов не использовать.

Миграции не требуются. Полная регистрация дохода расширением остаётся выключенной: настоящий результат ФНС представлен изображением blob, текущий адаптер результата его ещё не разбирает. Автоматическое письмо и кнопки доступны после получения подтверждённого чека; они не создают доход.
