# Проверка переноса — 16.10.2026

Рабочий сайт остаётся на main `21e147f`. Изменения находятся в `codex/timeweb-postgres-migration`, не опубликованы. Исходная база и её задания не изменены.

## Подтверждено

- TLS исходного PostgreSQL 17.6 через сессионный IPv4 pooler с официальным CA; прямой IPv6 недоступен из текущей сети.
- TLS новой Timeweb PostgreSQL 18.6 с проверкой имени и официальным CA.
- Полная новая схема и таблицы Better Auth проверены на Timeweb внутри транзакции с ROLLBACK. Выборочный импорт завершён COMMIT в PostgreSQL 18.6. Проверены 4 тарелки по 10 штук, количества всех 11 таблиц, пустота 24 исключённых таблиц и последовательность счетов. Временные расширение и схема сжатого импорта удалены; создана одна начальная учётная запись администратора, сессий нет.
- Панель Timeweb: Москва, 1 CPU, 2 ГБ RAM, 20 ГБ NVMe, 2 060 ₽/мес. Ресурс существовал до переноса. Автомасштабирование диска включено: порог 80%, шаг 5 ГБ; стоимость возможного увеличения не согласована.
- Физические копии включены: ежедневно с 00:15 МСК, хранится одна копия. Восстановление Timeweb пока не проверено. Логические копии и отмена удаления выключены.
- S3 доступен по TLS, бакет переведён в приватный; ACL не содержит публичных разрешений. Перенесены 58 связанных файлов, включая оригиналы и готовые размеры; каждый проверен чтением и SHA-256. Остальные 376 объектов остаются в исходной полной копии. Проверочный неподписанный запрос получил отказ. География ru-1 требует сопоставления с физическим размещением у провайдера.
- Сохранён закрытый локальный снимок исходного окружения приложения для отката. Тестовое окружение не содержит live-паролей Robokassa и Password3; создание отправлений отключено.
- Рабочие настройки Timeweb: ROBOKASSA_MODE=live, ROBOKASSA_LIVE_ENABLED=true, ROBOKASSA_SMZ_READY=true. Текст страницы доставки в новой версии берётся из серверного режима.
- 82 автоматических теста: 81 успешно, один старый тест пропущен из-за отсутствия своего отдельного стенда. Новые интеграционные тесты реального PostgreSQL выполнены: конкуренция за последний остаток, повтор оформления, повтор уведомления, отмена и восстановление резерва, SQL-права, вход/выход, CSRF, запрет регистрации и ограничение попыток входа.
- ESLint и TypeScript прошли. Производственная сборка прошла после исправлений запросов каталога и доставки. Поиск города и представления связей проверены отдельными тестами; все используемые цепочки методов запросов проверяются по исходному коду.
