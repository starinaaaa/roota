# Фотографии для страницы «О студии»

Загрузите фотографии в эту папку: `public/images/about/`.
Назовите их `01.jpg`, `02.jpg`, `03.jpg` и так далее в нужном порядке.
Подойдут JPG, PNG или WebP; желательно горизонтальные фотографии шириной
1920–2560 пикселей. Основной предмет лучше располагать по центру или справа:
слева поверх фотографии находится заголовок.

Фотографии `01.jpg`–`10.jpg` уже подключены. Для добавления новых фотографий
добавьте пути и описания в `aboutGallery` в файле `lib/about-gallery.ts`.
Затем сайт нужно заново собрать и опубликовать.
Пока список пуст, показывается главное фото из настроек сайта.
Файл `illustration.png` — рисунок для отдельного блока ниже, не для галереи.
